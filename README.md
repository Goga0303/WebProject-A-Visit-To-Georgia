# A Visit To Georgia 

A Visit To Georgia is a restaurant-themed web application built with **ASP.NET Core MVC**.  
The project was created as part of a university web development assignment and demonstrates MVC structure, navigation, and clean UI design.

---

##  Features
- ASP.NET Core MVC architecture (Models, Views, Controllers)
- Multiple pages with structured navigation
- Responsive layout with shared views
- Static assets (CSS/images) in `wwwroot`
- Database support with Entity Framework Core (if applicable)

---

##  Tech Stack
- C#
- ASP.NET Core MVC
- Entity Framework Core
- HTML / CSS
